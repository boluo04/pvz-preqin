# 先秦植物设定文档（精简版）

## 1. 约束

- 植物本体识别必须保留（不能做成纯人物/纯兵器）。
- 新机制优先复用现有逻辑：子弹替换、减速、范围伤害、护甲处理。
- 不要求新增僵尸受伤/死亡动画。

## 2. 已落地的3株（按当前实现）

### 2.1 秦弩射手（`QinCrossbowShooter`）

- 原型：`Peashooter`
- 阳光：150
- 冷却：7500ms
- 生命：300
- 攻击间隔：1.0s
- 子弹：普通弩箭（30伤害）
- 融合点：秦弩构件 + 甲片纹理，保留豌豆系轮廓

### 2.2 兵俑坚果卫（`BingYongWallNut`）

- 原型：`WallNut`
- 阳光：100
- 冷却：30000ms
- 生命：6000（普通坚果1.5倍）
- 机制：死亡触发十字5格爆炸（自身+上下左右）
- 爆炸伤害：900（樱桃1800的一半）
- 融合点：陶俑质感 + 裂损分阶段

### 2.3 礼乐向日葵（`LiYueSunFlower`）

- 原型：`SunFlower`
- 阳光：75
- 冷却：7500ms
- 生命：300
- 机制：每轮产2个阳光（各25）
- 融合点：青铜纹环 + 礼乐挂饰

## 3. 新增4株（已确认）

### 3.1 黑冰台树桩（暂名：`HeiBingTorchWood`）

- 原型：`TorchWood`
- 阳光：350
- 机制：
  - 所有穿过的豌豆子弹统一转为「紫焰附魔豌豆」：
    - 触发来源：普通豌豆、冰豌豆、火焰豌豆
    - 伤害：本体45、溅射20
    - 效果：附带冰冻减速（同冰豌豆）
  - 所有穿过的弩箭统一转为「紫焰附魔弩箭」：
    - 触发来源：普通弩箭、火焰弩箭
    - 伤害：本体68、溅射33
    - 效果：附带冰冻减速（同冰豌豆）
- 备注：替换逻辑沿用火炬树现有“过桩替换子弹”机制。

### 3.2 落网土豆雷（暂名：`LuoWangPotatoMine`）

- 原型：`PotatoMine`
- 阳光：50
- 伤害：2250（普通土豆雷1800的1.25倍）
- 伤害范围：保持原土豆雷范围（同一行近距爆炸）
- 新增机制：爆炸后对以自身为中心九宫格内僵尸施加5秒冰冻暂停
- 解冻行为：5秒后立即恢复正常（不附带额外减速）

### 3.3 白起樱桃炸弹（暂名：`BaiQiCherryBomb`）

- 原型：`CherryBomb`
- 阳光：225（普通樱桃150的1.5倍）
- 冷却：75000ms（普通樱桃50000ms的1.5倍）
- 伤害：3600（普通樱桃1800的2倍）
- 范围：沿用樱桃炸弹范围

### 3.4 墨磁菇（暂名：`MoFumeShroom`）

- 原型：`FumeShroom`（外观为大喷菇样式 + 金属护甲 + 磁铁标志）
- 阳光：225
- 生命：4000（同普通坚果）
- 攻击：大喷菇模式，伤害为普通大喷菇1.5倍
- 磁吸机制：
  - 仅判定“已进入草坪区域且玩家可见”的僵尸
  - 仅吸金属防具目标（铁桶、铁门）
  - 每45秒仅吸1次，优先吸离自身最近目标
  - 触发时目标缩小并被吸附到墨磁菇右上角（展示为小图标）

## 4. 子弹数值基线（用于调参）

- 普通豌豆：20
- 冰豌豆：20（附带减速）
- 火焰豌豆：本体27、溅射13
- 普通弩箭：30
- 火焰弩箭：本体45、溅射20（按当前策划目标）
- 紫焰附魔豌豆：本体45、溅射20（附带减速）
- 紫焰附魔弩箭：本体68、溅射33（附带减速）

## 5. 联调验收清单

- 黑冰台火炬树对子弹替换完整覆盖：普通/冰/火豌豆 + 普通/火弩箭。
- 紫焰附魔子弹命中后都触发减速，且不依赖僵尸新动画。
- 落网土豆雷伤害范围与原土豆雷一致，九宫格减速持续5秒且有可见特效。
- 白起樱桃炸弹费用、冷却、伤害按 1.5x/1.5x/2x 生效。
- 墨菇每45秒仅吸1次，只吸草坪内可见的铁桶/铁门目标，目标为最近单位。
