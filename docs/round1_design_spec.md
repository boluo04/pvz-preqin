# 先秦植物设定文档（精简版）

## 1. 约束

- 植物本体识别必须保留（不能做成纯人物/纯兵器）。
- 新机制优先复用现有逻辑：子弹替换、减速、范围伤害、护甲处理。
- 不要求新增僵尸受伤/死亡动画。

## 2. 已落地的3株（按当前实现）

### 2.1 秦弩射手（`QinCrossbowShooter`）

- 原型：`Peashooter`
- 阳光：150
- 冷却：7500ms
- 生命：300
- 攻击间隔：1000ms
- 子弹：普通弩箭（30伤害）
- 伤害类型：直线单体
- 融合点：秦弩构件 + 甲片纹理，保留豌豆系轮廓

### 2.2 兵俑坚果卫（`BingYongWallNut`）

- 原型：`WallNut`
- 阳光：100
- 冷却：30000ms
- 生命：6000（普通坚果1.5倍）
- 裂损状态：2段（裂损1/裂损2，阈值与坚果体系一致：≤2/3、≤1/3）
- 机制：死亡触发十字5格爆炸（自身+上下左右）
- 爆炸伤害：900（樱桃1800的一半）
- 爆炸范围：十字5格（自身+上下左右）
- 融合点：陶俑质感 + 裂损分阶段

### 2.3 礼乐向日葵（`LiYueSunFlower`）

- 原型：`SunFlower`
- 阳光：75
- 冷却：7500ms
- 生命：300
- 产阳光间隔：24000ms（与项目 `FLOWER_SUN_INTERVAL` 一致）
- 机制：每轮产2个阳光（各25，总计50）
- 融合点：青铜纹环 + 礼乐挂饰

## 3. 新增4株（已确认）

### 3.1 黑冰台树桩（暂名：`HeiBingTorchWood`）

- 原型：`TorchWood`
- 阳光：350
- 冷却：7500ms
- 生命：300
- 攻击：无（只做“过桩附魔”）
- 机制：
  - 所有穿过的豌豆子弹统一转为「紫焰附魔豌豆」：
    - 触发来源：普通豌豆、冰豌豆、火焰豌豆
    - 伤害：本体45、溅射20
    - 效果：附带冰冻减速（同冰豌豆）
  - 所有穿过的弩箭统一转为「紫焰附魔弩箭」：
    - 触发来源：普通弩箭、火焰弩箭
    - 伤害：本体68、溅射33
    - 效果：附带冰冻减速（同冰豌豆）
- 备注：替换逻辑沿用火炬树现有“过桩替换子弹”机制。

### 3.2 落网土豆雷（暂名：`LuoWangPotatoMine`）

- 原型：`PotatoMine`
- 阳光：50
- 冷却：30000ms
- 生命：300
- 起爆准备时间：15000ms（与土豆雷一致）
- 伤害：2250（普通土豆雷1800的1.25倍）
- 伤害范围：保持原土豆雷范围（同一行近距爆炸）
- 新增机制：爆炸后对以自身为中心九宫格内僵尸施加5秒冰冻暂停
- 解冻行为：5秒后立即恢复正常（不附带额外减速）
- 九宫格地块提示：触发九宫格冰纹特效（0.5s，位置略上移，尺寸约0.7倍）

### 3.3 白起樱桃炸弹（暂名：`BaiQiCherryBomb`）

- 原型：`CherryBomb`
- 阳光：300
- 冷却：125000ms（普通樱桃50000ms的2.5倍）
- 生命：∞（一次性爆炸类）
- 伤害：4200（定位“大杀器清场”）
- 生效范围（当前实现）：纵向5行（上下各2行，受地图边界限制）；横向≈3列（自身列左右各1列）
- 爆炸特效：爆炸帧缩放 2.5 倍；覆盖地块显示“白起范围标记”特效（0.7s）
- 备注：对泳池/黑雾关卡僵尸同样有效（按行组遍历结算，不区分地形）

### 3.4 墨磁菇（暂名：`MoFumeShroom`）

- 原型：`FumeShroom`（外观为大喷菇样式 + 金属护甲 + 磁铁标志）
- 阳光：225
- 冷却：7500ms
- 生命：4000（同普通坚果）
- 攻击：大喷菇模式（烟雾穿透），伤害30（普通大喷菇20的1.5倍）
- 攻击间隔：1400ms（沿用大喷菇节奏）
- 磁吸机制：
  - 仅判定“已进入草坪区域且玩家可见”的僵尸
  - 仅吸金属防具目标（铁桶、铁门）
  - 每45秒仅吸1次，优先吸离自身最近目标
  - 触发表现：目标僵尸被吸走并从场上移除；墨磁菇右上角显示吸附小图标（带飞入动画）

## 4. 拟加入：新一批特色植物 / 金卡（定稿待实现）

### 4.1 机枪连弩（暂名：`GatlingCrossbow`）

- 原型：`QinCrossbowShooter`
- 阳光：500
- 冷却：30000ms（建议）
- 生命：300
- 攻击方式：直线同一行
- 攻击节奏：
  - 每500ms触发一次三连发
  - 三连发出手时刻：t=0ms / 50ms / 100ms
- 子弹与伤害：完全沿用弩箭体系（不允许衰减）
  - 普通弩箭：30
  - 火焰弩箭：本体45、溅射20
  - 紫焰附魔弩箭：本体68、溅射33
- 与黑冰台树桩交互：穿过仍会附魔（沿用过桩替换）
- 备注：本体不受“帝国·军阵”影响（军阵只影响普通秦弩射手）

### 4.2 墨守坚壁·高坚果（暂名：`MoShouTallNut`）

- 原型：`TallNut`
- 阳光：350（建议）
- 冷却：45000ms（建议）
- 生命：20000（建议，用于对抗后期强化僵尸海）
- 裂损状态：2段（裂损1/裂损2；阈值≤2/3、≤1/3）
- 机制：无（纯血量防线）

### 4.3 金卡：帝国·军阵（技能卡，暂名：`EmpireFormation`）

- 规则：每局最多携带1张金卡
- 阳光：450（建议）
- 冷却：125000ms（建议）
- 触发方式：种下即触发（一次性技能卡），随后自身消失
- 持续时间：15秒
- 效果：
  - 持续期间：将所有普通秦弩射手（`QinCrossbowShooter`）临时切换为“机枪连弩”的攻击模式
  - 军阵结束后：上述临时改变的单位还原为普通秦弩射手
  - 不减伤、不衰减
  - 原本就种下的机枪连弩本体不受影响（不会被改变，也不会被还原）
- 视觉：全屏军阵特效（强烈的黑金秦阵纹/诏令压场）

### 4.4 金卡：玉玺·王命（技能卡，暂名：`JadeSealEdict`）

- 规则：每局最多携带1张金卡
- 阳光：550（建议）
- 冷却：150000ms（建议）
- 触发方式：种下即触发（一次性技能卡），随后自身消失
- 持续时间：12秒（建议）
- 效果：
  - 全场所有植物攻击力 +30%
  - 全场植物锁血：持续期间生命值最低保留1
  - 排除对象：一次性/灰烬植物（樱桃、白起樱桃、毁灭菇、辣椒、寒冰菇、土豆雷、倭瓜等）不享受锁血
- 视觉：全屏玉玺印章+诏令波纹；全体植物淡金描边闪烁

### 4.5 商鞅·变法豆（暂名：`ReformBean`）

- 阳光：75（建议）
- 冷却：15000ms（建议）
- 种植规则：不能单独种植，必须种在目标植物身上才生效；生效后自身消失
- 目标A：礼乐向日葵 → 大礼乐向日葵（`BigLiYueSunFlower`）
  - 结果：不可直接种植，只能通过变法豆获得
  - 外观：与礼乐向日葵同图，但整体放大
  - 产阳光：每轮产2个阳光（各50，总计100）
  - 阳光图标：比普通阳光更大（视觉上明确“高额阳光”）
- 目标B：兵俑坚果卫 → 墨守坚壁·高坚果
  - 满血状态：可直接变为 `MoShouTallNut`
  - 残损状态：只能修复一级（裂损2→裂损1，裂损1→满血）

## 4. 子弹数值基线（用于调参）

- 普通豌豆：20
- 冰豌豆：20（附带减速）
- 火焰豌豆：本体27、溅射13
- 普通弩箭：30
- 火焰弩箭：本体45、溅射20（按当前策划目标）
- 紫焰附魔豌豆：本体45、溅射20（附带减速）
- 紫焰附魔弩箭：本体68、溅射33（附带减速）

## 5. 联调验收清单

- 黑冰台火炬树对子弹替换完整覆盖：普通/冰/火豌豆 + 普通/火弩箭。
- 紫焰附魔子弹命中后都触发减速，且不依赖僵尸新动画。
- 落网土豆雷伤害范围与原土豆雷一致，九宫格减速持续5秒且有可见特效。
- 白起樱桃炸弹费用、冷却、伤害按 300/125000/4200 生效，范围为 3x5（纵向5行、横向3列）。
- 墨菇每45秒仅吸1次，只吸草坪内可见的铁桶/铁门目标，目标为最近单位。
