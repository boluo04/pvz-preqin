# 第1轮设计文档（先秦主题融合版）

## 1. 本轮目标

- 在不破坏《植物大战僵尸》“植物灵魂”的前提下，完成首轮先秦主题融合。
- 本轮优先实现“可运行、可识别、可平衡”，不追求一次性做复杂大改。
- 完成 3 个植物变体设计与 3 个僵尸变体框架占位。

## 2. 设计总原则（必须遵守）

### 2.1 植物优先原则
- 植物本体不能被“先秦元素”完全替代。
- 玩家必须一眼认出原植物类型（豌豆、坚果、向日葵）。

### 2.2 融合而非替换
- 先秦元素用于：服装、纹样、配件、特效风格、文案命名。
- 不允许把植物直接改成纯兵器/纯人物，避免失去 PVZ 原味。

### 2.3 小步快跑
- 首轮只做低风险功能改动。
- 新机制尽量控制在“轻量级”（例如低频反击），避免连锁失衡。

### 2.4 可读性优先
- 战斗中角色轮廓、动作、攻击方向要清晰。
- 特效不能遮挡核心信息（阳光、投射物、受击反馈）。

## 3. 本轮范围

### 3.1 包含内容
- 3 个植物变体详细设定（本文件已定义）
- 3 个僵尸变体占位（下阶段补细）
- 数值初稿、素材清单、接入清单、测试清单

### 3.2 不包含内容
- 新地图机制
- 全局经济重做
- 超大招随机秒杀机制（如始皇帝清全图）
- 寻路/AI 重写

## 4. 植物设定（Round-1）

## 4.1 豌豆射手变体：秦弩射手

**基础原型**
- `Peashooter`

**设计定位**
- 稳定远程输出，保持原版操作手感。

**保留项（不可变）**
- 豌豆射手头部轮廓、茎叶结构、正向发射识别度。
- 直线单体攻击机制。

**先秦融合项（可变）**
- 枪口处增加“小型秦弩构件”装饰。
- 增加简化先秦服饰/甲片纹理（低饱和土黄、青铜绿）。
- 投射物可做“豌豆弩丸”视觉风格，但大小和速度可读性保持原版。

**机制与数值 v0**
- 阳光消耗：100
- 生命值：300
- 伤害：20
- 攻击间隔：1.4 秒
- 新机制：无（首轮保持稳定）

**素材需求**
- 卡牌图标
- 待机动画
- 攻击动画
- 受击/死亡（可先复用）

**实现风险**
- 低

**测试重点**
- 投射物生成位置是否与新枪口装饰对齐。

## 4.2 坚果变体：兵俑坚果卫

**基础原型**
- `WallNut`

**设计定位**
- 前排抗线 + 死亡范围爆炸（满足“不能只挨打”且有记忆点）。

**保留项（不可变）**
- 坚果整体挡路轮廓。
- 裂纹受损阶段表现（高血量单位的读条感）。

**先秦融合项（可变）**
- 表面改为陶土质感 + 兵马俑刻纹。
- 裂损状态采用“陶土开裂”视觉强化。
- 可加小冠饰或肩纹，但不能改变碰撞轮廓。

**机制与数值 v0**
- 阳光消耗：75
- 生命值：4200
- 新机制：被彻底击杀时触发陶俑爆裂
- 爆炸范围：自身格 + 上下左右四格（十字5格）
- 爆炸伤害：樱桃炸弹伤害的 50%
- 触发限制：仅触发一次

**素材需求**
- 卡牌图标
- 满血外观
- 裂损1外观
- 裂损2外观

**实现风险**
- 中（需要在死亡结算中加入一次性范围爆炸）

**测试重点**
- 爆炸是否只触发一次，且范围严格为十字5格。
- 爆炸伤害是否为樱桃炸弹的一半，不出现误伤异常。

## 4.3 向日葵变体：礼乐向日葵（方案 A）

**基础原型**
- `SunFlower`

**设计定位**
- 经济核心，稳定产阳光。

**保留项（不可变）**
- 向日葵笑脸花盘和整体轮廓。
- 原版产阳光节奏与可读性。

**先秦融合项（可变）**
- 花盘边缘加入青铜纹环。
- 融入礼乐元素小挂饰（钟、磬、玉饰风格符号化处理）。
- 保持暖色主基调，避免看起来像攻击单位。

**机制与数值 v0**
- 阳光消耗：50
- 生命值：300
- 产出阳光：25
- 产出间隔：与原版一致
- 新机制：无（首轮不动经济节奏）

**素材需求**
- 卡牌图标
- 待机动画
- 产阳光动画
- 受击/死亡动画

**实现风险**
- 低

**测试重点**
- 装饰特效不能干扰阳光掉落与点击采集。

## 5. 僵尸设定（Round-1）

## 5.1 普通僵尸变体：流寇僵尸

**基础原型**
- `NormalZombie`

**设计定位**
- 基础兵线单位，保证早期节奏稳定。

**外观融合项**
- 破旧布甲 + 木片护具 + 流寇风头巾。
- 色调以灰褐、土黄为主，保持僵尸轮廓与动作辨识。

**机制与数值 v0**
- 完全沿用普通僵尸参数（首轮不改机制）。

**实现风险**
- 低

**测试重点**
- 与普通僵尸一致的移动和受击反馈。

## 5.2 路障僵尸变体：武士僵尸

**基础原型**
- `ConeheadZombie`

**设计定位**
- 轻甲前压单位，承担“比流寇更抗打”的中前期压力。

**外观融合项**
- 路障替换为破损胴丸/笠盔视觉。
- 保留“头部防具更硬”的直观识别。

**机制与数值 v0**
- 完全沿用路障僵尸参数（首轮不改机制）。

**实现风险**
- 低

**测试重点**
- 防具破损后的阶段切换是否清晰可见。

## 5.3 铁桶僵尸变体：罗马圆盾兵

**基础原型**
- `BucketheadZombie`

**设计定位**
- 重甲推进单位，提供后段压迫感。

**外观融合项**
- 桶类防具替换为罗马圆盾/头盔元素组合。
- 重点突出“重装兵种”体感与厚重配色。

**机制与数值 v0**
- 完全沿用铁桶僵尸参数（首轮不改机制）。

**实现风险**
- 低

**测试重点**
- 重甲单位受击反馈与击破节奏是否符合预期。

## 8. 美术规范（首轮）

- 优先保持原植物锚点与占地体积，减少代码适配成本。
- 透明底 PNG/WebP 流程与现有资源目录一致。
- 命名建议沿用当前项目风格，避免加载映射混乱。
- 装饰密度适中，确保小尺寸下仍能识别单位类型。

## 9. 接入清单（开发执行）

- 完成 3 个植物变体素材接入（或临时替换）。
- 将素材映射到现有植物类，优先少改逻辑。
- 为兵俑坚果卫加入“死亡一次性爆炸”机制。
- 僵尸侧本轮只做外观融合，不改行为逻辑。
- 运行基础冒烟测试：
  - 能启动游戏
  - 能放置 3 个新植物
  - 至少完成 1 胜 + 1 负
  - 暂停/主菜单/重开/铲子功能正常

## 10. 试玩验收清单

- 秦弩射手发射点与命中特效自然。
- 兵俑坚果卫死亡爆炸范围与伤害符合设定。
- 礼乐向日葵视觉不遮挡阳光掉落。
- 流寇僵尸/武士僵尸/罗马圆盾兵外观识别明确且不影响动作判定。
- 菜单切换不再出现卡死/未响应。
- 前两轮对局无运行时异常。
